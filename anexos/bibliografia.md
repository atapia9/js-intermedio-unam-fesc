# Anexo B. Bibliografía y referencias recomendadas

> **Nota de divulgación:** Este material fue elaborado con asistencia de Claude (Anthropic) y revisado por Jesús Armando Tapia Gallegos.

- MDN Web Docs — Mozilla Developer Network: [developer.mozilla.org/es/docs/Web/JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript)
- ECMAScript Language Specification (TC39): [tc39.es/ecma262](https://tc39.es/ecma262)
- Jest — documentación oficial: [jestjs.io/es-ES](https://jestjs.io/es-ES)
- Google Chrome DevTools — documentación oficial: [developer.chrome.com/docs/devtools](https://developer.chrome.com/docs/devtools)
- *Eloquent JavaScript*, Marijn Haverbeke (edición en línea, libre acceso): [eloquentjavascript.net](https://eloquentjavascript.net/). El sitio oficial enlaza también una [traducción al español](https://www.eloquentjavascript.es/).
- *You Don't Know JS* (serie), Kyle Simpson (repositorio en GitHub, libre acceso): [github.com/getify/You-Dont-Know-JS](https://github.com/getify/You-Dont-Know-JS). El repositorio contiene la segunda edición (*You Don't Know JS Yet*); la [primera edición](https://github.com/getify/You-Dont-Know-JS/blob/1st-ed/README.md) sigue disponible en la rama `1st-ed`.
